# Rexium Client Sayt - Tezkor Boshlash

## 3 daqiqada ishga tushiring! ⚡

### 1️⃣ GitHub Token oling (1 daqiqa)

1. https://github.com/settings/tokens
2. "Generate new token (classic)"
3. `repo` ruxsatini bering
4. Token ni nusxalang

### 2️⃣ auth.js ni sozlang (30 soniya)

```javascript
// auth.js, 4-6 qatorlar
const GITHUB_OWNER = 'sizning_username';
const GITHUB_REPO = 'rexium-client-data';
const GITHUB_TOKEN = 'token_ni_bu_yerga';
```

### 3️⃣ GitHub Pages ga yuklang (1 daqiqa)

1. GitHub da yangi repository: `rexium-client`
2. Barcha fayllarni yuklang
3. Settings > Pages > Source: main
4. Tayyor! ✅
